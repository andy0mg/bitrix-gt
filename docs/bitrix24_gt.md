# Скрипт `bitrix24_gt.sh`

Автоматизирует подготовку окружения для "Битрикс24". Помимо стандартного стека (Nginx, Apache, PHP‑FPM, MariaDB) устанавливаются Redis и push‑сервер для мгновенных уведомлений.

## Запуск
```bash
bash <(curl -sL https://raw.githubusercontent.com/YogSottot/bitrix-gt/master/bitrix24_gt.sh)
```
Скрипт рассчитан на Debian 11/12 и CentOS 7. Необходимы права суперпользователя и доступ в интернет.

## Основные шаги
1. **Логирование и определение ОС** – аналогично скрипту `bitrix_gt.sh`.
2. **Генерация паролей** – для пользователя MariaDB и ключа шифрования Bitrix.
3. **Функции конфигурации** – помимо PHP и MySQL создаются файлы настроек Redis (`redis.conf`) и агент в cron.
4. **Установка пакетов** – добавляются внешние репозитории, инсталлируются веб‑серверы, PHP 8.2, MariaDB, Redis, Node.js и `push-server`.
5. **Развёртывание дистрибутива** – скачивание `bitrixstable.tgz` и размещение файлов в `/var/www/html`.
6. **Настройка веб‑серверов** – Apache переводится в режим `mpm_worker`, конфигурируется Nginx и создаётся виртуальный хост для push‑сервера.
7. **Запуск Redis и push‑сервера** – выполняется подготовка конфигураций, создаются системные единицы `systemd`, сервисы добавляются в автозагрузку.
8. **Финальная проверка** – создаётся файл `/env` и проверяется доступность `bitrixsetup` на внешнем IP.

## Результат
Готовое окружение "Битрикс24" с поддержкой push‑уведомлений и Redis‑кэша.

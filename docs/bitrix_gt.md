# Скрипт `bitrix_gt.sh`

Скрипт предназначен для автоматической установки и настройки "Битрикс: Управление сайтом" на чистую систему. Поддерживаются Debian 11/12, CentOS 7 и Astra Linux. В процессе выполнения развертываются Nginx, Apache, PHP‑FPM и MariaDB.

## Запуск
```bash
bash <(curl -sL https://raw.githubusercontent.com/YogSottot/bitrix-gt/master/bitrix_gt.sh)
```
Скрипт требует прав суперпользователя и доступа в интернет.

## Основные шаги
1. **Логирование** – создаётся `/root/recipe.log` с полным выводом выполнения.
2. **Определение ОС** – пути конфигурационных файлов выбираются в зависимости от установленной системы.
3. **Генерация паролей** – случайные значения используются для пользователя `root` MariaDB и отдельного пользователя `bitrix`.
4. **Функции конфигурации** – скрипт формирует:
   - `dbconn.php` и `.settings.php` для каталога `/var/www/html/bitrix`;
   - параметры PHP в `z9_bitrix.ini` и пул FPM;
   - файл `z9_bitrix.cnf` для MariaDB;
   - задания агента в cron.
5. **Установка пакетов** – с помощью `apt` или `yum` устанавливаются веб‑серверы, PHP 8.2, MariaDB и вспомогательные утилиты.
6. **Развёртывание дистрибутива** – архив `bitrixstable.tgz` скачивается и распаковывается в `/var/www/html`.
7. **Настройка веб‑серверов** – включаются модули Apache, настраивается обратный прокси Nginx и права на каталог сайта.
8. **Запуск сервисов** – перезапускаются и добавляются в автозагрузку MySQL, Nginx, Apache и PHP‑FPM.
9. **Проверка** – в файле `/env` фиксируется строка `gt smart`, после чего скрипт проверяет доступность `bitrixsetup` по внешнему IP.

## Результат
На выходе получается готовое к инсталляции окружение Битрикс с преднастроенными компонентами и базой данных.
